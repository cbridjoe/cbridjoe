## 🔬 Featured Code Repositories

### 📁 [Topology-Preserving-Volumetric-Segmentation](https://github.com)
* **Language:** Python (`PyTorch`, `OpenCV`, `NumPy`)
* **The Architecture:** A standalone machine vision framework enforcing anatomical shape-guaranteed continuity across high-dimensional voxel matrices.
* **Key Innovations:**
  * Embedded a **spatial Jacobian regularizer loss constraint** inside the optimization loop to mathematically guarantee boundary bijectivity and prevent structural fracturing.
  * Configured an **aleatoric uncertainty head** calculating normalized Shannon entropy metrics to output real-time confidence heatmaps.
  * Formulated an **interactive real-time geodesic loss backpropagation engine** for clinician anchor point tuning without parameter collapse.

### 📁 [Subnational-Climate-Health-Surveillance-Pipeline](https://github.com)
* **Language:** R (`tidymodels`, `sparklyr`, `ggplot2`)
* **The Architecture:** An automated, reproducible spatiotemporal big data pipeline for proactive public health risk modeling.
* **Key Innovations:**
  * Automates **live ETL extraction** from remote gridded NASA POWER satellite arrays downscaled across 16 capital nodes.
  * Models complex, non-linear **multi-month mathematical time-lags** ($\Delta t = 1$ month for water-table shifts fueling diarrheal events; $\Delta t = 2$ months for vector extrinsic incubation windows driving malaria peaks).
  * Synthesizes an asymmetric **Composite Risk Index (CRI)** paired with a data-science optimized safety threshold at 0.82 to auto-dispatch clear-text alerts over low-latency SMS cellular gateways.
